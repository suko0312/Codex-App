# Codex Cloud 작업 지시서

## 1단계: 저장소 파악

Codex Cloud에서 첫 작업을 시작할 때 아래 프롬프트를 사용합니다.

```text
이 저장소는 병원 의국에서 사용할 환자 사진 정리 앱 초안입니다.

먼저 전체 프로젝트 구조를 파악해주세요.

반드시 읽을 파일:
- README.md
- AGENTS.md
- brand/DESIGN.md
- Context/buisiness-context.md
- Context/deck-brief.md
- index.html
- styles.css
- app.js

주의:
- 실제 환자 개인정보나 실제 환자 사진을 저장소에 추가하지 마세요.
- 현재 앱은 브라우저 프로토타입이며 실제 NAS 저장 기능은 아직 없습니다.

먼저 현재 기능과 한계를 간단히 요약하고, 다음 개발 순서를 제안해주세요.
```

## 2단계: UI 정리

```text
현재 브라우저 프로토타입 UI를 점검하고 개선해주세요.

유지해야 할 기능:
- 환자 이름, 등록번호 입력
- 진단명 여러 개 추가/삭제
- 수술명 입력
- 수술일 여러 개 추가/삭제
- 수술자 J, O, M, C, Y, L, Consult 버튼 선택
- 여러 사진 파일 추가
- JPEG EXIF 촬영일 기준 날짜 폴더 배정
- 수술일과 촬영일이 같으면 자동으로 (Op day) 처리
- 파일명은 환자이름마스킹_등록번호_촬영날짜-순서 형식

Windows 데스크톱 화면에서 의국원이 빠르게 사용할 수 있도록 문구와 배치를 다듬어주세요.
```

## 3단계: Electron 앱 전환

```text
브라우저 프로토타입을 Windows 데스크톱 앱으로 전환하는 계획을 세우고, Electron 기반 최소 앱 구조를 만들어주세요.

필수 조건:
- Windows에서 실행 가능
- 바탕화면 바로가기 또는 실행 파일로 열 수 있어야 함
- 기본 저장 경로는 다음 NAS 경로:
  \\10.10.72.128\성형외과공유폴더\★사진정리☆\★2026년 사진★\문석호 교수님 사진
- 실제 환자 사진은 저장소에 포함하지 말 것
- 저장 경로는 나중에 설정 파일에서 바꿀 수 있게 할 것

먼저 package.json, Electron main process, renderer 연결, 실행 스크립트까지만 구현해주세요.
```

## 4단계: 실제 저장 기능

```text
Electron 앱에서 실제 파일 저장 기능을 구현해주세요.

요구사항:
- 여러 사진 파일 선택 가능
- JPEG EXIF 촬영일 기준으로 날짜별 폴더 생성
- 촬영일이 수술일 목록 중 하나와 같으면 날짜 폴더 뒤에 (Op day) 추가
- Op Day 버튼이 눌린 상태면 선택한 사진 날짜 폴더에도 (Op day) 추가
- 파일명은 환자이름마스킹_등록번호_촬영날짜-순서번호.확장자
- 환자 이름은 중간 글자를 O로 마스킹
- NAS 경로 접근 실패 시 사용자가 이해하기 쉬운 오류 표시
- 실제 파일 복사 전 저장 미리보기 제공
- 저장 후 결과 요약 표시

테스트는 가짜 데이터로만 진행하고 실제 환자 정보는 넣지 마세요.
```

## 5단계: 검색 기능

```text
검색 탭 기능을 구현해주세요.

요구사항:
- 환자명, 등록번호, 진단명, 수술명, 수술자, 수술일로 검색
- 검색 결과 리스트 표시
- 결과 클릭 시 해당 NAS 폴더 열기
- 저장할 때 검색용 index.json 파일을 함께 업데이트하는 방식 검토
- 앱이 무거워지지 않도록 사진 미리보기는 선택 기능으로 설계
```
