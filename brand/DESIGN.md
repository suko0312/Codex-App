# DESIGN.md

## 문서 목적

이 문서는 환자 사진 정리 자동화 앱의 디자인 방향을 정리한 한글 제안서 초안입니다.

아직 앱을 만들기 전 단계이므로, 실제 화면 구현이 아니라 전체 분위기와 사용성 방향을 먼저 정리합니다.

## 디자인 방향 요약

이 앱은 병원 업무 중 반복되는 사진 정리 작업을 더 쉽고 정확하게 처리하기 위한 도구입니다.

디자인은 따뜻한 녹색 계열, 부드러운 베이지 톤, 차분한 우드톤 느낌을 참고합니다. 다만 특정 브랜드의 이름, 상징, 문구, 매장 이미지를 떠올리게 하는 요소는 사용하지 않습니다.

목표는 사용자가 업무 중 편안하게 집중할 수 있는 깨끗하고 신뢰감 있는 화면입니다.

## 전체 분위기

- 차분하고 신뢰감 있는 업무용 화면
- 너무 차갑지 않고 편안한 인상
- 병원 환경에 맞는 깨끗하고 정돈된 느낌
- 반복 작업을 빠르게 처리할 수 있는 단순한 구조
- 초보자도 바로 이해할 수 있는 쉬운 안내 문구

## 색상 제안

따뜻하고 안정적인 분위기는 유지하되, 의료 업무에 맞게 과하지 않게 사용합니다.

- 기본 배경: 따뜻한 흰색 또는 아주 연한 베이지
- 주요 버튼: 차분한 녹색 또는 짙은 청록색
- 보조 버튼: 밝은 회색 또는 연한 베이지
- 경고 표시: 부드럽지만 분명한 빨간색
- 완료 표시: 안정감 있는 초록색
- 구분선: 연한 회색 또는 낮은 채도의 베이지

색은 장식용이 아니라 사용자가 상태를 쉽게 이해하도록 돕는 역할로 사용합니다.

## 글자와 문구

글자는 작지 않고 또렷해야 합니다.

전문 용어보다는 사용자가 바로 이해할 수 있는 표현을 사용합니다.

예시 문구:

- "환자 정보 입력"
- "사진 선택"
- "저장 위치 확인"
- "저장하기"
- "저장이 완료되었습니다"
- "같은 이름의 폴더가 이미 있습니다"

## 화면 구성 원칙

1. 한 화면에는 꼭 필요한 정보만 보여줍니다.
2. 입력 순서는 실제 업무 순서와 비슷하게 만듭니다.
3. 저장 전에는 입력한 내용을 다시 확인할 수 있게 합니다.
4. 저장 후에는 결과를 분명하게 알려줍니다.
5. 사용자가 실수했을 때 쉽게 수정할 수 있어야 합니다.

## 주요 화면 흐름 제안

1. 환자 이름, 등록번호, 진단명을 입력합니다.
2. 날짜를 선택하거나 자동 입력된 날짜를 확인합니다.
3. 저장할 사진 파일을 선택합니다.
4. 앱이 만들 폴더 구조를 미리 보여줍니다.
5. 사용자가 확인 후 저장 버튼을 누릅니다.
6. 저장 완료 또는 오류 내용을 보여줍니다.

## 버튼 디자인 제안

- 가장 중요한 버튼은 한눈에 보이도록 색을 분명히 합니다.
- 보조 버튼은 차분한 색으로 표시합니다.
- 버튼 이름은 짧고 직접적으로 작성합니다.
- 예: "저장하기", "다시 선택", "취소", "폴더 열기"

## 피해야 할 요소

- 특정 브랜드 이름 사용
- 특정 브랜드를 떠올리게 하는 상징, 문구, 이미지 사용
- 장식이 많아 업무를 방해하는 화면
- 너무 작은 글씨
- 복잡한 메뉴 구조
- 저장 결과를 알기 어려운 화면

## 제안서용 한 줄 설명

이 앱은 따뜻하고 차분한 업무용 디자인을 바탕으로, 환자 사진 정리 과정을 쉽고 정확하게 자동화하는 도구를 목표로 합니다.
