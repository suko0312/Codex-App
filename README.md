# 환자 사진 정리 앱 초안

## 프로젝트 목적

이 프로젝트는 환자 사진과 정보를 사람이 직접 폴더에 정리하던 방식을 앱으로 자동화하기 위한 초안입니다.

현재 목표는 실제 운영 앱을 완성하는 것이 아니라, 의국원들이 사용할 화면 흐름과 저장 규칙을 먼저 확인하는 것입니다.

## 현재 초안에서 가능한 기능

- 환자 이름, 등록번호 입력
- 진단명 여러 개 추가 및 삭제
- 수술명 입력
- 수술일 여러 개 추가 및 삭제
- 수술자 `J`, `O`, `M`, `C`, `Y`, `L`, `Consult` 버튼 선택
- 여러 사진 파일 선택
- JPEG/JPG 사진의 EXIF 촬영일 기준 날짜 폴더 미리보기
- 촬영일이 수술일과 같으면 `(Op day)` 자동 표시
- 환자 이름 중간 글자를 `O`로 바꾼 파일명 미리보기
- 검색 탭 화면 초안

## 기본 NAS 저장 경로

```text
\\10.10.72.128\성형외과공유폴더\★사진정리☆\★2026년 사진★\문석호 교수님 사진
```

현재 브라우저 초안은 위 경로를 화면에 표시하고 저장 계획을 보여주지만, 실제 파일 복사는 아직 하지 않습니다.

## 실행 방법

`index.html` 파일을 브라우저에서 열면 초안 화면을 볼 수 있습니다.

또는 로컬 미리보기 서버를 사용할 수 있습니다.

```powershell
node preview-server.mjs
```

그 다음 브라우저에서 아래 주소를 엽니다.

```text
http://127.0.0.1:4173
```

## 중요한 주의사항

실제 환자 개인정보나 실제 환자 사진은 GitHub, Codex Cloud, 저장소에 올리지 않습니다.

테스트할 때는 가짜 이름, 가짜 등록번호, 샘플 사진만 사용합니다.

## 다음 개발 방향

실제 NAS 폴더에 파일을 복사하려면 브라우저 초안만으로는 한계가 있습니다.

다음 단계에서는 Windows 데스크톱 앱 형태, 예를 들면 Electron 앱으로 전환하는 방향이 좋습니다.

Electron 앱으로 만들면 다음 기능을 구현할 수 있습니다.

- NAS 폴더 접근 확인
- 폴더 자동 생성
- 사진 파일 실제 복사
- 저장 실패 시 오류 안내
- 바탕화면 바로가기 또는 실행 파일 배포
