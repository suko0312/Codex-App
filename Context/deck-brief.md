# deck-brief.md

## 문서 목적

이 문서는 이 프로젝트를 제안서나 발표자료로 정리할 때 사용할 핵심 내용을 모아둔 초안입니다.

나중에 슬라이드 자료를 만들 때 이 문서를 기준으로 문제, 목표, 기능, 기대효과를 정리할 수 있습니다.

## 프로젝트 한 줄 소개

환자 사진과 정보를 사람이 직접 폴더에 정리하던 방식을, 앱을 이용해 더 쉽고 정확하게 자동화하는 프로젝트입니다.

## 현재 문제

현재는 환자 사진을 정리할 때 담당자가 직접 폴더를 만들고 사진을 옮겨야 합니다.

환자 이름, 등록번호, 진단명, 날짜를 사람이 직접 입력하기 때문에 실수가 생길 수 있습니다.

또한 사진이 많아질수록 원하는 환자나 수술 관련 사진을 다시 찾는 데 시간이 오래 걸릴 수 있습니다.

## 해결 방향

앱에서 환자 정보와 사진을 입력하면, 앱이 자동으로 폴더를 만들고 사진을 날짜별로 정리합니다.

사진과 폴더는 개인 컴퓨터가 아니라 NAS 서버 안의 지정된 위치에 저장하는 방향을 고려합니다.

의국원들은 각자 바탕화면 아이콘을 눌러 앱을 실행하고, 앱은 내부적으로 다음 서버에 접근합니다.

```text
\\10.10.72.128
```

우선 사용할 실제 저장 폴더는 다음 위치입니다.

```text
\\10.10.72.128\성형외과공유폴더\★사진정리☆\★2026년 사진★\문석호 교수님 사진
```

사진 파일명도 정해진 규칙에 따라 자동으로 바꾸어, 나중에 확인하기 쉽게 만듭니다.

수술일에 해당하는 사진은 `(Op day)` 표시가 붙은 폴더로 구분하여 관리합니다.

## 주요 입력 정보

- 환자 이름
- 등록번호
- 진단명
- 수술명
- 수술자
- 수술일
- 사진 파일

## 주요 기능 초안

- 바탕화면 아이콘으로 앱 실행
- NAS 서버의 지정 폴더에 접근
- 환자 정보 입력
- 수술자 버튼 선택
- 사진 파일 추가
- 사진 촬영 날짜 기준 자동 분류
- 수술일 사진 자동 표시
- `Op Day` 버튼을 통한 수술일 사진 수동 표시
- 사진 파일명 자동 변경
- 환자명, 등록번호, 진단명, 수술명, 수술일 기준 검색
- 검색 결과에서 해당 사진 폴더로 이동
- 가능하다면 앱 안에서 사진 미리보기 제공

## 수술자 선택 버튼 초안

수술자는 직접 입력하지 않고, 미리 정해진 버튼 중 하나를 눌러 선택하는 방식으로 생각합니다.

버튼 예시는 다음과 같습니다.

- J
- O
- M
- C
- Y
- L
- Consult

이 방식은 표기 실수를 줄이고, 나중에 검색하거나 정리할 때 기준을 통일하는 데 도움이 됩니다.

## 사진 파일명 규칙 초안

사진 파일명은 다음 형식으로 자동 변경합니다.

```text
환자이름마스킹_등록번호_촬영날짜-촬영순서.jpg
```

예시:

```text
홍O동_12345678_2026-05-29-1.jpg
홍O동_12345678_2026-05-29-2.jpg
```

환자 이름의 중간 글자는 개인정보 보호를 위해 `O`로 대체합니다.

## 기대효과

- 반복적인 폴더 생성 작업을 줄일 수 있습니다.
- 사진을 잘못된 폴더에 넣는 실수를 줄일 수 있습니다.
- 의국원들이 같은 서버 위치를 기준으로 자료를 관리할 수 있습니다.
- 수술일 사진을 쉽게 구분할 수 있습니다.
- 환자 정보를 기준으로 사진 자료를 더 빨리 찾을 수 있습니다.
- 업무 시간이 줄고 자료 관리가 더 일관되게 유지됩니다.

## 추후 확인이 필요한 사항

- 최종 폴더 이름 규칙
- 날짜 표기 방식
- 수술자 정보가 폴더명이나 파일명에 포함되어야 하는지
- 수술자 버튼의 실제 의미와 표시 이름
- 이름이 두 글자이거나 네 글자 이상일 때 마스킹 방식
- 사진 촬영 날짜 정보가 없는 파일 처리 방식
- 앱 안에서 사진 미리보기를 처음부터 넣을지 여부
- 각 의국원 컴퓨터의 NAS 접근 권한 확인 방식
- 매년 사진 폴더가 바뀔 때 저장 경로 변경 방식
- 개인정보 보호를 위해 필요한 추가 규칙
