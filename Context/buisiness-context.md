# buisiness-context.md

## 문서 목적

이 문서는 환자 사진 정리 자동화 앱의 업무 배경과 원하는 기능을 정리한 문서입니다.

나중에 앱을 만들 때, 왜 이 앱이 필요한지와 어떤 흐름으로 사용되면 좋은지 쉽게 이해할 수 있도록 작성합니다.

## 현재 업무 방식

현재는 환자 사진과 정보를 정리할 때 사람이 직접 폴더를 만들고 사진을 옮기는 방식입니다.

대략적인 흐름은 다음과 같습니다.

1. 환자 이름, 등록번호, 진단명을 확인합니다.
2. 이 정보를 이용해 환자 폴더를 만듭니다.
3. 환자 폴더 안에 날짜별 하위 폴더를 만듭니다.
4. 사진 파일을 해당 날짜 폴더에 직접 붙여넣습니다.
5. 나중에 필요할 때 폴더를 열어 사진을 확인합니다.

## 현재 방식의 불편한 점

- 같은 형식의 폴더를 매번 직접 만들어야 합니다.
- 이름, 등록번호, 진단명 등을 잘못 입력할 수 있습니다.
- 날짜 폴더를 빼먹거나 날짜 형식이 달라질 수 있습니다.
- 사진을 잘못된 환자 폴더에 넣을 위험이 있습니다.
- 반복 작업이 많아 시간이 걸립니다.
- 나중에 특정 환자나 수술 정보를 다시 찾기 어렵습니다.

## 앱 사용 흐름 초안

사용자는 바탕화면의 앱 아이콘을 눌러 프로그램을 실행합니다.

앱은 각 의국원의 개인 컴퓨터에서 실행되지만, 실제 사진과 폴더는 NAS 서버 안의 지정된 폴더에 저장되는 방식이면 좋겠습니다.

서버 주소는 다음과 같습니다.

```text
\\10.10.72.128
```

우선 사용할 저장 폴더는 다음 위치입니다.

```text
\\10.10.72.128\성형외과공유폴더\★사진정리☆\★2026년 사진★\문석호 교수님 사진
```

즉, 의국원들은 바탕화면 아이콘을 눌러 앱을 실행하고, 앱은 내부적으로 위 NAS 폴더에 접근하여 환자 사진을 정리합니다.

앱이 실행되면 사용자는 다음 정보를 입력합니다.

- 환자 이름
- 등록번호
- 진단명
- 수술명
- 수술자
- 수술일

그 다음 사진을 추가하는 버튼을 눌러 사진 파일을 선택합니다.

앱은 선택한 사진 파일의 촬영 날짜를 확인하고, 촬영 날짜에 맞춰 각각의 날짜 폴더에 사진을 나누어 저장합니다.

## Op Day 처리 방식 초안

수술일에 촬영된 사진은 나중에 쉽게 알아볼 수 있어야 합니다.

이를 위해 다음과 같은 방식이 필요합니다.

1. 사진을 추가할 때 사용자가 `Op Day` 버튼을 누른 상태로 입력하면, 해당 날짜 폴더 이름 뒤에 `(Op day)`를 붙입니다.
2. 사용자가 `Op Day` 버튼을 따로 누르지 않아도, 사진 촬영 날짜가 미리 입력한 수술일과 같다면 자동으로 `(Op day)`를 붙입니다.

예시:

```text
환자이름_등록번호_진단명_수술명/
  2026-05-29 (Op day)/
    사진1.jpg
    사진2.jpg
  2026-05-30/
    사진3.jpg
```

위 구조는 임시 예시입니다. 실제 폴더 이름 규칙은 나중에 확인 후 정해야 합니다.

## 수술자 선택 방식 초안

수술자는 직접 글자로 입력하는 방식보다, 미리 정해진 버튼 중에서 선택하는 방식이면 좋겠습니다.

수술자 선택 버튼 예시는 다음과 같습니다.

- J
- O
- M
- C
- Y
- L
- Consult

사용자는 해당 버튼을 눌러 수술자를 선택합니다.

이 방식은 입력 실수를 줄이고, 같은 수술자를 항상 같은 표기로 기록하는 데 도움이 됩니다.

## 검색 기능 초안

앱에는 별도의 검색 탭이 있으면 좋겠습니다.

검색 탭에서는 다음 정보로 환자 자료를 찾을 수 있어야 합니다.

- 환자 이름
- 등록번호
- 진단명
- 수술명
- 수술자
- 수술일

검색 결과는 리스트 형태로 보여주면 좋습니다.

사용자가 검색 결과 중 하나를 클릭하면, 해당 환자의 사진 폴더로 이동할 수 있어야 합니다.

## 사진 확인 기능 초안

앱의 용량이 너무 커지지 않고 속도가 느려지지 않는다면, 앱 안에서 사진 파일을 미리 볼 수 있는 창이 있으면 좋겠습니다.

이 기능이 가능하다면 사용자는 폴더를 직접 열지 않고도 앱 안에서 사진을 확인할 수 있습니다.

다만 앱이 무거워질 가능성이 있다면, 처음에는 폴더로 이동하는 기능을 우선 만들고 사진 미리보기는 나중에 추가해도 됩니다.

## 사진 파일 이름 자동 변경 규칙 초안

사진 파일은 저장될 때 자동으로 이름이 바뀌면 좋겠습니다.

파일 이름에는 다음 정보를 넣습니다.

- 환자 이름
- 등록번호
- 촬영 날짜
- 같은 날짜 안에서의 촬영 순서

개인정보 노출을 줄이기 위해 환자 이름의 중간 글자는 `O`로 대체합니다.

예시:

```text
홍길동 -> 홍O동
김철수 -> 김O수
이민지 -> 이O지
```

파일 이름 예시는 다음과 같습니다.

```text
홍O동_12345678_2026-05-29-1.jpg
홍O동_12345678_2026-05-29-2.jpg
홍O동_12345678_2026-05-29-3.jpg
```

같은 촬영 날짜에 여러 장의 사진이 있으면 촬영 순서대로 `-1`, `-2`, `-3`처럼 번호를 붙입니다.

촬영 순서는 가능하면 사진 파일의 촬영 시간 정보를 기준으로 정렬합니다. 만약 촬영 시간 정보가 없다면, 사용자가 선택한 파일 순서나 파일의 기본 정렬 순서를 사용할 수 있습니다.

## 자동화하고 싶은 방향

앱에서 환자 정보와 사진을 입력하면, 앱이 정해진 규칙에 따라 폴더를 만들고 사진을 저장하도록 하고 싶습니다.

사용자는 NAS 서버의 폴더를 직접 찾아 들어가거나 폴더를 직접 만들 필요 없이 필요한 정보와 사진만 입력하면 됩니다.

## 앱이 해주면 좋은 일

- 환자 정보로 폴더 이름을 자동으로 만들기
- 수술명과 수술일 정보를 함께 기록하기
- 수술자를 버튼으로 선택하여 기록하기
- NAS 서버 안의 `\\10.10.72.128\성형외과공유폴더\★사진정리☆\★2026년 사진★\문석호 교수님 사진` 폴더에 사진 저장하기
- 사진 촬영 날짜를 기준으로 날짜별 하위 폴더 만들기
- 수술일 사진은 `(Op day)` 표시가 붙은 폴더에 저장하기
- 사진 파일 이름을 정해진 규칙에 따라 자동으로 바꾸기
- 선택한 사진을 올바른 위치에 복사하기
- 저장 결과를 사용자에게 보여주기
- 이미 같은 폴더가 있을 때 안내하기
- 검색 탭에서 환자 자료를 쉽게 찾기
- 검색 결과에서 바로 사진 폴더로 이동하기

## 아직 결정되지 않은 것

- 폴더 이름의 정확한 순서
- 날짜 형식
- 수술자 정보가 폴더 이름이나 파일 이름에 포함되어야 하는지
- 수술자 버튼의 실제 의미와 표시 이름
- 이름이 두 글자이거나 네 글자 이상일 때 어느 글자를 `O`로 바꿀지
- 사진 촬영 날짜 정보를 어떻게 읽을지
- 사진에 촬영 날짜 정보가 없을 때 어떻게 처리할지
- 같은 날짜에 이미 같은 번호의 사진 파일이 있을 때 처리 방식
- 같은 환자가 여러 번 수술했을 때 처리 방식
- 앱 안에서 사진 미리보기를 처음부터 넣을지 여부
- 의국원 컴퓨터에서 NAS 서버 접근 권한을 어떻게 확인할지
- 매년 사진 폴더가 바뀔 때 저장 경로를 어떻게 변경할지
- 개인정보 보호를 위해 추가로 필요한 규칙

## 예시 폴더 구조 초안

```text
환자이름_등록번호_진단명_수술명/
  2026-05-29 (Op day)/
    사진1.jpg
    사진2.jpg
  2026-06-01/
    사진3.jpg
```

이 구조는 임시 예시입니다. 실제 규칙은 사용자가 확인한 뒤 확정해야 합니다.
